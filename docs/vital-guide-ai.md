# Vital Guide AI preview
- Public corpus: src/lib/vitalGuideSources.ts contains approved-for-public sources and short attributed takeaways. Current entries come from Vital Edge's public website and official Medicare, CMS, and SSA pages. The customer-facing app must not receive credentials or access to the native ChatGPT Project, client records, CRM, or unreviewed uploads.
- Adding a Project source: select the exact document and section with its owner. Confirm suitability for public use, remove private client and agency details, verify current official sources where appropriate, and add the approved public takeaway and citation to the catalog in a reviewed PR. Re-review when guidance changes. No runtime sync from private Project content.
- AI selects IDs and their order. It cannot supply answer copy, URLs, enrollment recommendations, or tool actions. A follow-up receives only the bounded prior catalog IDs, not a transcript. The app suppresses recognized sensitive information and selected plan-specific requests before the provider call; this filtering is not a guarantee. The UI tells people not to enter personal details and discloses provider processing.
- Activation: for an access-restricted Vercel preview only, configure VITAL_GUIDE_AI_ENABLED=true and provision a working server-side OPENAI_API_KEY plus optional OPENAI_MODEL in that preview. Do not expose the credential to the browser. The feature is deliberately disabled on Vercel production regardless of configuration. If no provider responds, public quick topics and Patrick's call, schedule, and contact paths still work.
- Before any public release: verify the protected real-provider preview using synthetic questions only, confirm provider data handling and user-facing notice, set project rate/spend limits and an edge-level throttle, and get Patrick's approval for the source catalog and release. Do not substitute local fixture results for provider verification.
